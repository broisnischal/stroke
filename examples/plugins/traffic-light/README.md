# Traffic Light

An example Stroke plugin. Colours numeric latency, score and percentage columns
green, amber or red.

Install it from Stroke: Extensions panel, `+`, pick this folder. Then turn it on
and open a table with a `latency_ms` or `score` column.

Editing `main.js` and pressing Reload in the panel is the whole development
loop: no build step, no bundler, no restart.

See `docs/PLUGIN_API.md` in the Stroke repository for the full contract.
